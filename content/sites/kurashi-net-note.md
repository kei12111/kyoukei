# くらしネットノート 収益化プラン（1サイト目の試行）

作成: 2026-10-05
前提: サイト内容は「住まいのネット回線選びを助けるサイト」と推測（スクショのタイトルとサムネのみで判断）。違っていたら本人が修正する。

## なぜこのサイトから
- 光回線・ホームルーターの案件は単価が高めになりやすい（金額は未確認。ASP管理画面で確認）
- 既存の「学生×通信費」ニッチと重なり、X・Shortsを使い回せる
- 「どの回線にするか」で迷っている人＝申込直前の人が来るサイト

## 手順
- [ ] 1. ChatGPT Sites（またはCodex）の規約で、外部アフィリエイトリンクと広告表示が使えるか確認
- [ ] 2. A8.net / もしもアフィリエイト / バリューコマースに登録（無料）
- [ ] 3. 下の「案件候補」をASPで検索し、Sitesへの掲載で提携申請できるか確認 → `tracking/offers.csv` に記録
- [ ] 4. 提携が承認された2〜3件のURLで、下の「Codexへの依頼文」を実行
- [ ] 5. 公開後、スマホでPR表記・リンク先・表示崩れを確認
- [ ] 6. X投稿（下）を1日1本ずつ
- [ ] 7. 週1回、閲覧数・クリック数を `tracking/articles.csv` に記録（媒体＝ChatGPT Sites）

## 案件候補（すべて【未確認】。報酬・条件・ASPは管理画面で確認してから使う）
| 種類 | 候補 | 合う読者 |
|---|---|---|
| 光回線 | ドコモ光 / ソフトバンク光 / auひかり / 楽天ひかり | 持っているスマホとセット割を使いたい人 |
| ホームルーター | ドコモ home 5G / WiMAX系 / Rakuten Turbo | 工事できない賃貸・一人暮らし・短期間だけ住む人 |
| ポケット型Wi-Fi | 各社 | 外でもPCを使う学生 |

選び方: 本人が楽天モバイル契約中なので、楽天ひかり / Rakuten Turbo は「スマホとのセットで考えた」という一次情報を書きやすい。ただし未使用の回線を「使ってみた」とは書かない。

## リンクを置く場所
1. 診断・比較結果のすぐ下（一番クリックされやすい）
2. 「賃貸で工事ができない人は」など、条件別の分岐の直後
3. ページ最下部のまとめ（1か所だけ）
※ ページ全体で同じ案件のリンクは3か所まで。押し売りに見えると離脱される。

## Codexへの依頼文（コピペ用。[ ] を埋める）
```
ChatGPT Sitesの「くらしネットノート」を収益化したい。今のデザインと内容は崩さずに、以下を追加して。

1. ページ最上部に小さく「当サイトはアフィリエイト広告（PR）を含みます」と表示する。
2. 診断・比較の結果を表示している場所のすぐ下に「条件に合う回線」枠を作る。
   - [回線名A]：[一言の特徴]　リンク [ASPで発行したURL-A]
   - [回線名B]：[一言の特徴]　リンク [ASPで発行したURL-B]
   - [回線名C]：[一言の特徴]　リンク [ASPで発行したURL-C]
   ※ 料金や特典の数字は書かず「料金・特典は公式ページで確認してください」と添える。
3. 結果に応じておすすめを出し分ける:
   - 工事できない／賃貸／短期間 → ホームルーター（[回線名]）を先に表示
   - 長く住む／家族で使う／在宅ワーク → 光回線を先に表示
4. アフィリエイトリンクはすべて rel="sponsored nofollow" を付け、新しいタブで開く。
5. ページ下部に「情報の確認日: [YYYY-MM-DD]」を表示する。
6. 外部リンクやスクリプトが使えない仕様なら、無理に入れず、その旨を教えて。
```

## 書かないこと（ステマ・景表法対策）
- 「絶対お得」「最安」などの断定（根拠になる比較日と出典がない場合）
- 使っていない回線の体験談
- 公式で確認していない料金・キャッシュバック額

## X投稿（1日1本。リンク付きは最後の1本だけ）
1. 回線を選ぶ前に「工事できる家か」を確認した方がいい。賃貸だと管理会社の許可が必要なことがあり、ここで選択肢が半分に変わる。
2. 光回線かホームルーターか迷ったら「あと何年その家に住むか」で考える。短期なら工事不要の方が身軽。長く住むなら速度・安定性で光を候補に。
3. ネット回線は月額だけで比べると失敗しやすい。工事費・解約金・スマホとのセット割まで含めて「2年でいくらか」で見る。
4. 一人暮らしの学生は「スマホのテザリングだけで足りるか」も一度考える。私はスマホで月24GB使っていて、PC作業が増えると足りない側。
5. 自分の住まい・使い方から回線のタイプを絞れるページを作りました。料金は各社の公式で確認してください。→ [サイトURL] ※広告を含みます

## 8週後の判断
- 閲覧が少ない → X・Shortsのフックを変える（サイトは触らない）
- 閲覧はあるがクリックが少ない → リンクの位置と文言を1つだけ変える
- クリックはあるが成果ゼロ → 案件を差し替える
- 成果が出た → 同じ形を「かりる前ノート」（引越し・賃貸）に横展開
