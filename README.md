# kyoukei — 学生×通信費 アフィリエイト検証プロジェクト

0円で8週間、「学生×通信費（格安SIM/eSIM）」ニッチで売れる経路を見つける。

## 成功条件（3か月時点）
- 同一ニッチで確定成果 3件以上
- 月100回程度の広告主クリック
- 反応の良いテーマを1つ特定

## 原則
- 開始時の現金支出は0円（note / X / YouTube Shorts / ASP / Canva Free）
- 1リサーチ → note1本 → X5投稿 → Shorts2本 に再利用
- 記事冒頭に広告表示（ステマ規制対応）
- 未使用の商品を「使ってみた」と書かない。実体験・公式情報・推測を分ける
- 料金は「○月○日確認」を明記し、公式ページで再確認
- 有料広告・WordPress・有料ツールは、成果3件が出るまで契約しない
- 週5〜8時間を基準に継続

## 構成
- `checklists/` 週ごとのTODO
- `tracking/` 案件・記事の計測シート（CSV）
- `content/calendar.md` 8週間の投稿計画
- `content/drafts/` 記事・X・Shortsの下書き
- `templates/` 比較記事 / X / Shorts テンプレート

## 8週目の判断ルール
- 閲覧が増えない → タイトル・配信方法・Shortsのフックを直す
- 閲覧はあるがクリックなし → 検索意図と案件のズレ
- クリック約100件で成果ゼロ → 案件/LP構造を変える
- 特定テーマだけ成果 → そのテーマ周辺に5〜10記事追加
- 3か月で確定成果3件 → 独自サイトを投資候補に
